# Nout — Өзіңе сай ноутбук

Қазақ тіліндегі ноутбук таңдау сайты. HTML, CSS және JavaScript; сыртқы JavaScript кітапханалары мен орнатылатын тәуелділіктер жоқ. Google Fonts қолжетімсіз болса, жүйелік қаріп қолданылады.

## Жергілікті іске қосу

Node.js 20 немесе жаңа нұсқасы қажет. Жоба қалтасында:

```sh
node server.mjs
```

Браузерде http://127.0.0.1:4173 ашыңыз. `index.html` файлын `file://` арқылы ашпаңыз: каталог HTTP арқылы жүктеледі.

Тексеру:

```sh
node --test tests/catalog.test.mjs
```

PowerShell-де npm script саясаты кедергі болса, `npm.cmd start` немесе жоғарыдағы `node` пәрменін қолдануға болады.

## Мүмкіндіктер

- Оқу, бағдарламалау, кеңсе, күрделі жұмыс, ойын және қолжетімді модельдер бойынша іріктеу.
- Бюджет, бренд, RAM, жинақтауыш, GPU түрі/сериясы, CPU тобы, экран өлшемі, ОЖ және салмақ сүзгілері.
- Модель, процессор, графика және басқа сипаттамалар бойынша іздеу; баға, салмақ, жыл бойынша реттеу.
- Үш сұрақтан тұратын түсіндірілетін ұсыныс көмекшісі.
- Үш модельге дейін салыстыру; ресми өндіруші беттеріне сілтемелер.
- Таңдаулылар мен салыстыру тізімін браузердің localStorage жадына сақтау.
- Мобильді көрініс, пернетақта басқаруы, қолжетімді диалог атаулары, reduced-motion қолдауы.

## Файлдар

- `dist/index.html`: бет құрылымы.
- `dist/styles.css`: бейімделетін дизайн мен анимациялар.
- `dist/app.js`: интерфейс пен localStorage.
- `dist/catalog.js`: таза сүзгілеу және ұсыныс функциялары.
- `dist/data.json`: каталог және дереккөздер.
- `dist/assets/`: кодпен жасалған SVG иллюстрациялар. Нақты тауар фотолары емес.
- `DATA-SOURCES.md`: деректердің шығу тегі және толықтыру жолдары.
- `.openai/hosting.json`: Sites жариялау конфигурациясы.

## Деректердің шектеулері

Бастапқы каталогта 7 брендтен 24 конфигурация бар, оның ішінде ресми дереккөздермен тексерілген 2026 модельдері бар. Бұл барлық ноутбуктің толық базасы емес. Кей жазбалар модель сериясындағы конфигурацияны сипаттайды; жергілікті нақты SKU қолжетімділігі тексерілмеген.

Барлық бағалар — сүзгілерге арналған шартты бюджет бағдары. Олар дүкен бағасы, нарықтық баға немесе коммерциялық ұсыныс емес. Автоматты баға/қор жаңартуы жоқ. Салмақ шамамен беріледі; белгісіз салмақ `null`. Surface Laptop 13 жинақтауышы UFS болғандықтан, интерфейсте жалпы «жинақтауыш» атауы қолданылады.

`dist/data.json` ішіндегі `laptops` массивіне сол схема бойынша тексерілген модель қосып, ресми `sourceUrl`, тексерілген күн және тиісті конфигурацияны көрсетіңіз. Өндірушіден табылмаған сипаттамаларды ойдан толтырмаңыз. Жаңартудан соң тесттерді іске қосып, `updatedAt` өрісін жаңартыңыз. Open Icecat каталогын және Қазақстан дүкендерінің рұқсат етілген прайс-фидтерін қосу нұсқалары `DATA-SOURCES.md` ішінде жазылған. Ешқандай API кілті бұл жобаға қосылмаған.

## Тексеру нәтижесі

9 автоматты тест: сүзгілерді бірге қолдану, іздеу, GPU/ОЖ/экран шарттары, белгісіз мәндер, реттеу, таңдаулылар, бюджет/мақсат шарттары, ұсыныс басымдықтары, бастапқы массивтің өзгермеуі.

Edge браузерінде каталогтың жүктелуі, екі модельді салыстыру, үш қадамды ұсыныс көмекшісі және 400 px мобильді көрініс тексерілді. Мобильді сүзгілер ашылады, карточкалар мен салыстыру панелі экран еніне бейімделеді.
